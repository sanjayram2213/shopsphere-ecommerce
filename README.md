🛍️ ShopSphere – E-Commerce Website

ShopSphere is a responsive e-commerce website developed using HTML, CSS, and JavaScript. It provides a simple and user-friendly online shopping experience with product browsing, wishlist management, and shopping cart functionality.

🌐 Live Demo

"Visit ShopSphere" (https://sanjayram2213.github.io/shopsphere-ecommerce/)

✨ Features

- Responsive Design: Works on desktop, tablet, and mobile devices.
- Product Display: Browse a collection of shopping products.
- Product Search: Find products using the search bar.
- Category Filter: Filter products by category.
- Wishlist: Add and remove favourite products.
- Shopping Cart: Add products and manage quantities.
- Cart Total: Automatically calculates the total price.
- Local Storage: Saves wishlist and cart data after refreshing the page.
- Demo Checkout: Experience a sample order process without real payment.

🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Website functionality and interactivity
- Local Storage – Saving cart and wishlist data
- GitHub Pages – Website hosting
